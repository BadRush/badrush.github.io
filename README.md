# Anam Badrus Salam — Portfolio Site

Website portofolio pribadi dan CV digital yang dirancang untuk menampilkan pengalaman profesional, keahlian teknis, dan proyek di bidang **Network Engineering & NOC**.

## ✨ Fitur Utama
- **Modern & Premium UI**: Desain berbasis *Glassmorphism* dengan tema gelap yang elegan.
- **Fully Responsive**: Dioptimalkan untuk perangkat mobile, tablet, dan desktop.
- **Interactive Experience**: Animasi *Scroll Reveal* dan ikon interaktif menggunakan Lucide & Simple Icons.
- **Visitor Statistics**: Pelacakan statistik kunjungan situs secara *real-time* di bagian footer.
- **Quick Links**: Akses cepat ke Resume, CV Lengkap, dan kanal komunikasi (LinkedIn, GitHub, Telegram).

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik yang ramah SEO.
- **CSS3 (Modular)**: Penggunaan variabel desain (tokens) dan arsitektur CSS modular.
- **Lucide Icons**: Ikon vektor modern yang ringan.
- **Simple Icons**: Ikon brand (GitHub, LinkedIn, dll) yang konsisten.
- **Vanilla JavaScript**: Untuk logika navigasi, animasi scroll, dan inisialisasi ikon.

## 🚀 Deployment
Situs ini dihosting menggunakan **GitHub Pages**. Setiap perubahan pada branch `main` akan secara otomatis diperbarui ke:
[badrush.github.io](https://badrush.github.io)

## 📁 Struktur Proyek
- `index.html`: Halaman utama portofolio.
- `cv.html` & `resume.html`: Halaman dokumen profesional.
- `res/css/`: Direktori modul CSS (Base, Components, Hero, Sections, Responsive).
- `res/script.js`: Logika interaksi utama.
- `res/images/`: Aset gambar dan aset latar belakang.
