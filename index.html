Secara aktif mengembangkan solusi otomasi dan internal tools mulai dari backup konfigurasi multi-vendor otomatis, sistem alerting cerdas berbasis Telegram, hingga aplikasi manajemen logistik data center menggunakan Python dan AI-Assisted Development untuk mengakselerasi efisiensi operasional tim NOC secara signifikan.
